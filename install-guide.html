Install the Ferry Timer

Add the Ferry Timer to an iPhone, iPad, or Android phone as an app with its custom icon. Installation takes about a minute.

Open Ferry Timer

iPhone or iPad

Use Safari

  1. Open Safari and visit the Ferry Timer using the button above.
  2. Tap the Share button, the square with an upward arrow.
  3. Scroll down and tap Add to Home Screen.
  4. Turn on Open as Web App, if that option appears.
  5. Confirm the name, then tap Add.
  6. Open the new Ferry Timer icon from the Home Screen.
  7. Choose Allow While Using App and leave Precise Location on.

Android

Use Google Chrome

  1. Open Google Chrome and visit the Ferry Timer using the button above.
  2. Tap Chrome's three-dot menu.
  3. Tap Install app or Add to Home screen, depending on the phone.
  4. Tap Install and follow the on-screen prompt.
  5. Open the new Ferry Timer icon from the Home Screen or app launcher.
  6. Choose While using the app and allow precise location.
  7. If prompted, allow Chrome to use location services.

Using the Ferry Timer

1Open the iconGPS will attempt to start automatically.
2Check the routeConfirm Summerville or Millidgeville.
3Watch the marginThe timer shows how far ahead or behind you are.

Quick fixes

  • No custom icon? Remove the shortcut, reopen the newest app address in Safari or Chrome, and install it again.
  • No location? Open the phone's Privacy or Location settings, enable Location Services, and allow precise location while using the app.
  • Old version showing? Fully close and reopen the app. If needed, remove it and reinstall from this page.
  • GPS did not start? Tap Start GPS Timer in the app.

Drive safely: Set the timer before driving and keep the phone mounted. The app estimates arrival; ferry space and service are not guaranteed.
